# SlideLink

[![Tests](https://github.com/Dejiu-Zhang/slidelink/actions/workflows/test.yml/badge.svg)](https://github.com/Dejiu-Zhang/slidelink/actions/workflows/test.yml)

**一个属于你的演示工作台。电脑给观众看 slides，iPad 给你看 slides、讲稿和批注。**

上传 HTML slides 和逐页讲稿，生成一对独立链接。在 iPad 翻页或标注 slides，电脑实时跟随；右侧讲稿和私人批注不发送给投屏端。用文件夹整理项目，在同一项目中保留多个版本。

## 第一版已经包含

- 项目库、搜索、文件夹、项目重命名和移动。
- 同一项目上传新版本，查看历史版本、下载原始文件、删除单个版本。
- 每个版本各自的投屏链接和演讲者链接；新版不会替换旧链接。
- iPad 左侧 slides、右侧逐页讲稿；可调整分栏、字号、计时和全屏。
- 上传预览逐页编辑讲稿；演讲者页面右侧直接编辑，保留本标签页草稿，点击“保存新版本”持久化并保留旧稿。
- 公开批注：压力画笔、荧光笔、激光笔、橡皮、撤销、清除、框选与套索移动。
- 私人批注：讲稿上单独圈画，仅保存在演讲者浏览器当前标签页。
- WebSocket 同步、连接提示、自动重连、投屏重新加载后补回当前页批注。
- 工作空间密钥隔离不同人的项目；投屏密钥不能读取讲稿或控制演讲。
- 持久化文件存储、可选过期清理、Docker 部署、自动化测试。

这是可运行的早期版本，适合个人及受邀小团队。它还不是带邮箱登录、团队协作、计费和大规模存储的公共 SaaS。

## 本地运行

需要 Node.js 24 或以上。

```sh
npm ci
npm start
```

打开 `http://127.0.0.1:3000`，点击“先体验一个示例”。本地默认仅绑定回环地址；这个地址不能直接从另一台设备访问。跨设备演示请部署 HTTPS 服务，或按照 [部署说明](docs/DEPLOYMENT.md) 使用可信的局域网配置。

首次访问会在浏览器中创建一个随机工作空间密钥。请到“工作空间设置”备份密钥。在另一台电脑粘贴同一密钥，就能打开同一个项目库。朋友使用自己的浏览器会得到自己的空白工作空间。此版本没有邮箱登录或密码找回。

## 使用流程

1. 新建文件夹（可选），点击“新建演示项目”。
2. 上传一个自包含的 HTML slides 文件，上传或粘贴 TXT / Markdown 讲稿。
3. “检查并预览”：确认页数、版面尺寸及每页讲稿，再保存。
4. 电脑打开“投屏”，iPad 打开“演讲者”。电脑连接投影；iPad 不做整屏镜像。
5. iPad 翻页或在左侧 slides 上写画，电脑同步。右侧讲稿、字号调整、私人批注不会投屏。
6. 修改后在原项目点“上传新版本”。每个版本保留独立内容和链接。

右侧点“编辑讲稿”即可修改，完成后点“保存新版本”。保存成功会给出新版的两个链接，并在原项目增加一条版本记录。正在进行的投屏仍使用原链接，不会被保存动作打断。草稿只在当前浏览器标签页暂存；正式保存后，修改才会进入服务器项目库。私人手写批注与文字讲稿分开保存，保存讲稿不会将笔迹写进新版本。

一个版本同一时刻由一个演讲者窗口控制。新打开的演讲者窗口会接管旧窗口，避免两个控制器冲突。可以同时打开多个只读投屏窗口。

## 讲稿格式

用一行 `---` 分隔，页数必须与 slides 完全对应。某页无讲稿时保留一个空白段。Markdown 暂按原始文本显示，不执行其中的 HTML。

```text
第一页的讲稿。

这里可以标注停顿、重音、提醒。
---
第二页的讲稿。
---
第三页的讲稿。
```

也支持 `# Slide 1`、`# Slide 2` 或 `# 第 1 页` 标题。未提供独立讲稿时，尝试读取 HTML 中的 `.notes`、`.speaker-notes` 或 `[data-speaker-notes]`。

## HTML 支持范围

按优先级识别 `[data-lecture-slide]`、`[data-slide]`、Reveal.js 的 `.reveal .slides section`、`.slide`。嵌套 Reveal.js 页展开为线性顺序。默认画布为 1200 × 675，可在上传时调整。

保留静态内容、内联 CSS、SVG、data URL 图片与字体、已经渲染的公式。相对路径素材不会随单个 HTML 自动上传：先把图片、字体、样式内嵌，或将图片和字体改为公开 HTTPS 地址。不要上传只有 JavaScript 运行后才生成内容的页面。

当前不执行上传 HTML 中的 JavaScript，也不保留 fragment 动画、视频播放器、嵌入网页或任意页面交互。Reveal.js 外链主题样式需要先内联，且应检查预览。尚不直接接收 PPTX、PDF、DOCX 或 ZIP 资源包。

单份 HTML 限制 6 MB、最多 120 页。预览必须通过后才能保存，不承诺任意 HTML 均能自动适配。

## 分享给别人

有两种方式：

- **让朋友直接使用**：把项目部署成一个 HTTPS 网站，分享首页和上传口令。每位朋友有独立工作空间；不用 GitHub，也不用安装插件。
- **让别人自行部署**：分享代码仓库，对方克隆后按部署文档启动自己的实例。

不要把你自己的工作空间密钥或演讲者链接当作网站入口分享。投屏链接也属于有权限的私人链接；知道链接的人可以看对应 slides。

GitHub 保存代码，网站服务负责文件和实时连接。这个版本不能直接部署为 GitHub Pages；详见 [部署说明](docs/DEPLOYMENT.md)。

## 数据与权限

- HTML、讲稿、项目、版本及链接存储在服务端 `data/`，不会进入 Git 仓库。默认持续保留，设置 `RETENTION_DAYS` 可自动过期。
- 工作空间密钥仅在浏览器保存；服务端按其 SHA-256 摘要匹配所有者。它是项目库的访问凭证，请备份。
- 投屏与演讲者使用不同的随机密钥，链接密钥放在 URL 的 `#fragment` 中，通过请求头／WebSocket 首条消息提交验证。
- 投屏 API 使用字段白名单，独立上传的讲稿不传给投屏浏览器；标准内嵌 speaker notes 会从导入的 slide 内容中移除。上传前仍需检查自定义 HTML 本身是否含有不想公开的文字、图片或 CSS 内容。
- 导入内容在不允许脚本的 sandbox iframe 中呈现，不与工作空间页面共享 DOM 权限。
- 服务器验证 WebSocket 身份，屏蔽投屏端的翻页和批注写入，并只转发允许的消息字段。
- TLS 保护传输；本版本没有端到端加密，部署者可以读取服务器中保存的文件和链接。不要将敏感材料上传到不信任的实例。
- 公开及私人笔迹保存在演讲者当前浏览器标签页的 sessionStorage。它们不是服务器版本历史的一部分，关闭标签页、清除网站数据或换设备后可能丢失；源文件和讲稿才是持久化的版本内容。
- 服务器仅保留单进程内的实时连接。关闭或重启服务会短暂断连，浏览器会重连；演讲者保持打开时可以补发批注。

## 测试

```sh
npm test
npx playwright install chromium
npm run test:browser
```

已有 Chrome 的机器也可以使用 `TEST_CHROME=1 npm run test:browser`。测试包含工作空间隔离、讲稿隔离、版本不覆盖、删除与服务器重启、WebSocket 权限、两个独立浏览器上下文中的翻页/笔迹同步、断网恢复、页面刷新和截图。模拟触控和笔输入不能替代真实 iPad / Apple Pencil 的现场测试。

## 来源

画笔和同步逻辑由作者现有 [演讲者页面](https://dejiu-zhang.github.io/x/i5gztqq4mu/presenter.html) 中的 SlideLink 提取，新增同源身份验证传输、静态导入、项目库和版本管理。内嵌的 perfect-freehand 保留了原 MIT 许可证，见 [第三方说明](THIRD_PARTY_NOTICES.md)。

已有 `.pv-script[data-i]` 讲稿页面可通过导入脚本迁移到运行中的实例：

```sh
node scripts/import-existing.mjs --slides ./slides.html --presenter ./presenter.html
```

脚本会校验页数并输出私人工作空间入口和两个演示链接；已有工作空间可用 `--workspace` 指定。原始演示文件和个人访问链接不包含在公开代码仓库中。
